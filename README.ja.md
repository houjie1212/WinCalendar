# WinCalendar

[简体中文](README.md) | [English](README.en.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md)

Windows の右下にある時計をクリックして、カレンダー、祝日、予定を確認できます。

**[最新版をダウンロード](https://github.com/houjie1212/WinCalendar/releases/latest)** · [問題を報告](https://github.com/houjie1212/WinCalendar/issues)

Windows 11 x64 向けです。実行環境を別途インストールする必要はありません。Windows の各バージョンでの動作確認状況は[開発ガイド（中国語）](docs/development.md#兼容与验证)をご覧ください。

- **インストーラー版（推奨）**：`WinCalendar-Setup-{version}-x64.exe` をダウンロードし、案内に従ってインストールします。
- **ポータブル版**：`WinCalendar-{version}-win-x64.zip` をすべて展開し、`WinCalendar.exe` を実行します。フォルダー内のファイルはまとめて保管してください。

インストーラーは未署名のため、Windows に発行元不明の警告が表示される場合があります。上記のリリースページからダウンロードしてください。

## 主な機能

- **祝日と振替出勤日**：対応する中国の祝日カレンダーを購読すると、祝日名、休日、振替出勤日のマークを表示できます。
- **中国旧暦の表示**：設定で中国旧暦を有効にすると、日付と一緒に表示できます。
- **カレンダーの購読**：中国、日本、米国の祝日を簡単に追加できます。自分のカレンダーの購読リンクも使用できます。
- **色分け**：購読ごとに背景色を設定できます。同じ日には最大 3 色を表示し、すべての予定を詳細で確認できます。
- **月の切り替え**：年月の選択、矢印ボタン、マウスホイールに対応。「今日」で当日に戻れます。
- **システムに合わせた表示**：ライト／ダークテーマに追従し、簡体字中国語、繁体字中国語、英語、日本語に対応します。

## 使い方

1. WinCalendar をインストールして起動します。他のタスクバー用カレンダーツールは先に終了してください。
2. 右下の時計をクリックするとカレンダーが開きます。もう一度クリックするか、パネルの外側をクリックするか、Esc キーを押すと閉じます。
3. 歯車ボタンから設定を開き、プリセットを選ぶか、「購読を追加」で自分のリンクを入力します。
4. 購読の編集画面を保存した後、設定画面でも「保存」をクリックします。中国旧暦や自動起動もここで有効にできます。

## よくある質問

### 祝日や旧暦が表示されないのはなぜですか？

初期状態では購読は追加されておらず、旧暦も無効です。「中国の祝日」のプリセットを追加して有効にすると、対応する祝日と出勤日のマークが表示されます。独自のリンクでは種類を「中国の祝日」に設定し、対応する形式の配信元を使う必要があります。旧暦は別途有効にしてください。

通常のカレンダーでは予定と色を表示しますが、中国の休日・出勤日マークは生成しません。予定のタイトル、場所、説明は配信元の言語のまま表示します。

### 購読の更新頻度は？更新に失敗した場合は？

初期設定では 30 分ごとに更新します。間隔は設定で変更できます。「今すぐ更新」は設定を保存してから最新の予定を取得します。失敗した場合も、ダウンロード済みの予定は残ります。

直接アクセスできる公開インターネット上のカレンダーリンクのみ対応しています。社内ネットワーク上のリンクやプロキシが必要な購読は更新できません。接続とリンクを確認してください。カレンダーの読み取り専用で、元の予定の編集やアカウントへのログインには対応していません。

### アプリを更新するには？

設定の「更新を確認」をクリックし、新しいバージョンがあれば案内に従って更新・再起動します。自動での更新確認やダウンロードは行いません。未保存の設定は先に保存してください。

更新に失敗した場合は、リリースページから最新版のインストーラーをダウンロードし、上書きインストールしてください。設定と購読は保持されます。

### 終了・アンインストールするには？

設定で「終了」を選ぶと、時計のクリック時の動作が元に戻ります。自動起動は初期状態では無効で、設定から有効にできます。

インストーラー版は、設定の「アンインストール」または Windows の「インストールされているアプリ」から削除できます。**初期設定では、購読、設定、ダウンロード済みデータも削除します。** 残す場合は、購読と設定を保持する項目にチェックを入れてください。アンインストールをキャンセルした場合は削除しません。

### データの保存場所は？

設定とダウンロード済みの予定は、PC の `%LOCALAPPDATA%\WinCalendar` フォルダーに保存します。

購読アドレスは暗号化して保存します。別の PC や Windows アカウントに移行した場合、再入力が必要になることがあります。ダウンロード済みの予定は暗号化されないため、データフォルダー全体を共有しないでください。この保護は、すでに現在のアカウントを乗っ取ったプログラムによる読み取りを防ぐものではありません。
