# WinCalendar

[简体中文](README.md) | [English](README.en.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md)

点击 Windows 右下角时间，查看日历、假日和日程。

**[下载最新版](https://github.com/houjie1212/WinCalendar/releases/latest)** · [反馈问题](https://github.com/houjie1212/WinCalendar/issues)

适用于 Windows 11 x64，无需额外安装运行环境。不同 Windows 版本的验证情况见[开发说明](docs/development.md#兼容与验证)。

- **安装版（推荐）**：下载 `WinCalendar-Setup-版本号-x64.exe`，按提示安装。
- **便携版**：下载 `WinCalendar-版本号-win-x64.zip`，完整解压后运行 `WinCalendar.exe`，请保留整个文件夹。

Windows 可能显示未知发布者提示，当前安装包尚未签名。请从上方发布页下载。

## 主要功能

- **假日与休班**：添加兼容的中国节假日订阅，查看节日名称和“休／班”标识。
- **可选农历**：在设置中开启“中国农历”，与日历一起显示。
- **日历订阅**：提供中国、日本、美国假日快捷选项，也可添加自己的日历订阅链接。
- **颜色区分**：用不同背景色区分订阅，同一天最多显示三种颜色，完整日程仍可查看。
- **快速翻月**：支持年月下拉选择、左右按钮和鼠标滚轮，点击“今天”返回当天。
- **跟随系统**：自动适应深浅主题，支持简体中文、繁体中文、英文和日文。

## 快速开始

1. 安装并启动 WinCalendar；如正在使用其他任务栏日历工具，请先退出。
2. 点击右下角系统时间打开日历。再次点击、点击面板外部或按 Esc 即可收起。
3. 点击齿轮打开设置，选择常用订阅，或通过“添加订阅”填写自己的链接。
4. 保存订阅编辑窗口后，再点击设置页“保存”。需要农历或开机启动时，可在这里开启。

## 常见问题

### 为什么没有节假日和农历？

默认不添加任何订阅，农历也默认关闭。在设置中添加并启用“中国节假日”常用订阅后，就能显示对应假日和休班标识；自定义链接需要选择“中国节假日”类型，且来源格式兼容。农历需单独开启。

普通日历订阅会显示日程和颜色，不会生成中国休班标识。订阅中的标题、地点和描述保持原文。

### 订阅多久更新？失败了怎么办？

默认每 30 分钟更新，可在设置中调整。“立即刷新”会先保存设置，再获取最新日程；失败时保留已下载的日程。

仅支持可直接访问的公网日历链接，内网或依赖代理的订阅无法刷新。请检查网络和链接是否可用。程序只读取日历，不修改原来的日程，也不提供账号登录。

### 如何更新？

在设置中点击“检查更新”，有新版本时按提示更新并重启。程序不会自动检查或下载更新；未保存的设置需要先保存。

如果更新失败，可从发布页下载新版安装包覆盖安装，保留原有设置和订阅。

### 如何退出或卸载？

在设置中点击“退出”，系统时间会恢复原来的打开方式。开机启动默认关闭，可在设置中开启。

安装版可通过设置中的“卸载”，或 Windows 的“已安装的应用”卸载。**卸载默认删除订阅、设置及已下载的数据**；需要保留时，请勾选“保留订阅和设置”。取消卸载不会删除数据。

### 数据保存在哪里？

设置和已下载的日程保存在本机 `%LOCALAPPDATA%\WinCalendar` 文件夹。

订阅地址加密保存，换电脑或 Windows 账户后可能需要重新填写；已下载的日程未加密，请勿直接分享整个数据文件夹。这种保护不能阻止已控制当前账户的程序读取数据。
