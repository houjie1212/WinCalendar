# WinCalendar

Windows 11 x64 日历：点击系统时间打开，默认显示公历，支持自定义 ICS 日历；启用中国节假日订阅后显示节日名称和“休／班”标识。

## 使用

1. 解压独立运行包到固定目录，运行 `WinCalendar.exe`。整个目录必须一起保留。
2. 使用前退出 WinCal 或其它接管系统时钟的程序，避免争抢点击。
3. 点击任务栏原来的时间区域打开；再次点击、点击外部或按 Esc 收起。
4. 点击齿轮进入设置，添加 HTTPS 或 Webcal 订阅链接。可添加多个源、选择颜色、启停、编辑或删除。
5. 默认每 30 分钟刷新；“立即刷新”先保存当前设置并更新数据。自启动默认关闭，可在设置中启用。
6. 退出程序：设置 → 退出。退出后，系统时间点击恢复原生行为。

订阅为单向读取，不修改源日历，不支持账号登录或日程回写。带令牌的私人链接保存在本机配置，不输出到日志。订阅标题、地点和描述保持原文。

## 卸载

安装版可在设置页点击“卸载”，或从 Windows“已安装的应用”进入卸载向导。应用内入口会先退出程序，未保存的修改不会自动保存。便携版或安装目录不匹配时，该按钮不可用。

卸载向导提供“保留订阅和设置”选项，**默认不勾选**；继续卸载将删除设置、订阅、缓存及更新备份。勾选后保留，取消卸载不删除数据。静默卸载默认保留数据。遇到目录链接或文件占用时，保留无法安全删除的条目并提示残留位置。

## 检查更新

设置页版本号旁点击“检查更新”，从 `houjie1212/WinCalendar` 的 GitHub Releases 查询正式版。确认后下载、校验并重启更新；不会后台检查或自动下载。未保存设置需先保存才能继续。

更新要求使用完整独立发行目录（包含 `release-files.json`），并有目录写权限及足够磁盘空间。配置与订阅仍保存在 `%LOCALAPPDATA%\WinCalendar`，更新不修改自启动路径。SHA-256 用于下载完整性校验，不是独立的代码签名；发行包未签名。

发布者运行 PowerShell 7 脚本 `Scripts/build-release.ps1`（可用 `-NuGetSource` 指定源）。脚本检查并生成 `publish/releases/WinCalendar-{版本}-win-x64.zip` 和 `SHA256SUMS.txt`；手动上传到相同版本的正式 Release，例如标签 `v1.0.1`，并填写更新说明。工程版本与标签必须一致。脚本不推送代码或创建 Release。

更新在 `%LOCALAPPDATA%\WinCalendar\Updates\{任务编号}` 保留恢复记录和备份。启动失败会回滚；断电后程序仍能启动时自动继续恢复。如果主程序已无法启动，可在该任务的 `worker` 目录运行 `WinCalendar.exe --recover-update "任务目录的完整路径"`。恢复失败时保留备份，解除文件占用后重试；不要删除未完成任务的目录。成功更新后的任务目录可在退出程序后手动删除。

线上检查和升级需仓库已公开发布更高版本及两个完整资产；只有源码提交不会产生可用更新。

## 常用订阅

设置页提供中国节假日（蓝色）、日本假日（红色）、美国联邦假日（紫色）快捷选项。点击后预填编辑窗口，可修改名称、链接、类型和颜色；编辑保存后仍需保存设置页才生效。取消不会新增订阅。

中国使用 ShuYZ 兼容源并预选“中国节假日”类型；日本和美国使用 Office Holidays 公开源，按普通日程显示，标题保持源语言。不会自动添加订阅。

所有常用订阅均可选择来源：中国提供放假及补班、仅放假、仅补班；日本提供标题含国家名称、隐藏国家名称、包含非公共假日；美国提供仅联邦假日，以及公共／地区假日的含国家名称、隐藏国家名称、包含非公共假日版本。每次保存一个地址。

主动选择“自定义地址”会清空地址栏并聚焦输入框；再次打开或切换界面语言不会清空已经填写的地址。

已有同组预置地址时打开已有订阅编辑窗口，保留用户字段和启停状态；保存时阻止重复地址。名称保存后不会因界面切换语言而自动更名。

## 日期与语言

- 月历标题提供年份（1901—2100）和月份下拉框，可直接跳转年月；箭头和“今天”继续可用。切换年月保留原选中日期，复用相邻月份预加载；下拉框打开时滚轮操作列表，Esc 先关闭列表。

- 月份按钮和滚轮切换时保留原选中日期，并预加载前后各一个月的完整网格。预加载完成后切换相邻月份可立即显示假日与订阅背景；翻月仅解析本地缓存，不额外下载。快速跨越预加载范围时仍需等待后台加载，期间保留已有内容。

- 有日程的日期格以订阅颜色背景显示，替代圆点；同日多个订阅按设置列表顺序从左到右等宽分区，最多显示前 3 个有效订阅，每个订阅占一份，同源多个事件不重复分区。超出部分仍显示在悬停提示和当天详情中。同色来源仍保留各自份额，悬停提示列出全部来源。选中日期以边框突出，保留订阅背景。

- 默认仅显示公历、普通周末颜色及用户订阅日程。设置页可开启“中国农历”，保存后显示农历日期，重启保留；取消不生效。
- 农历初一显示月份（含闰月），其他日期显示日序；订阅节日名称优先，农历保留在日期提示中。农历不自动生成传统节日或休班标识，超出 .NET 支持范围留空。
- 在订阅编辑中选择“普通日历”或“中国节假日”；旧订阅保持普通日历，需要手动修改类型。
- 中国节假日源启用后，日期格显示名称与休班角标；停用或删除并保存后立即移除。
- 首先兼容 ShuYZ 完整日历，复制以下链接并选择“中国节假日”类型：

```text
https://raw.githubusercontent.com/lanceliao/china-holiday-calender/master/holidayCal.ics
```

- 仅识别完整标题“节日名 假期 第N天/共N天”和“节日名 补班 第N天/共N天”；未知格式仍显示日程，不推断休班。其他来源不保证支持角标。
- 日期格按源日历日期标记；定时详情按系统本地时区显示，可能落在不同日期。全天结束日期不包含在事件中。
- 多源同日休班冲突时隐藏角标，日期提示说明冲突；多个名称按订阅顺序展示首个，提示和带来源名称的日程详情保留全部信息。
- 界面跟随 Windows 显示语言，内置简中、繁中、英文、日文；其他语言回退英文。日期、时间与默认周起始日跟随系统区域格式。
- 已知节日名称和休班角标本地化；ICS 原始标题、地点、描述不翻译。没有订阅数据的日期不补充节假日。

## 本地数据

配置和缓存位于 `%LOCALAPPDATA%\WinCalendar`：

- `settings.json`：订阅和显示设置。
- `订阅标识.ics`：最后一次成功下载的订阅内容。

不自动添加订阅，不读取或更新旧 `holiday-年份.json` 缓存，也不主动删除这些旧文件。订阅更新失败保留最后有效缓存；损坏配置不会被静默覆盖。

## 构建与检查

需要 .NET 8 SDK。在工程目录运行：

```powershell
dotnet build WinCalendar.csproj --disable-build-servers -p:UseSharedCompilation=false
dotnet run --project Checks/Checks.csproj
dotnet publish WinCalendar.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=false -o publish/win-x64
```

独立发布包使用 .NET 8.0.30，不需要安装运行时。基础检查使用本机 .NET 8。

开发诊断（不会写入用户订阅）：

```powershell
dotnet bin/Debug/net8.0-windows/WinCalendar.dll --probe-clock clock-probe.txt
dotnet bin/Debug/net8.0-windows/WinCalendar.dll --integration-check integration-results.txt
```

`--preview` 为界面调试模式，暂停失焦关闭并显示任务栏图标；日常使用请不带该参数。`--background` 为自启动使用的后台模式。

## 边界与验收

- 时间入口采用 UI Automation 识别和鼠标钩子，不注入 Explorer，不先打开原生日历再隐藏。按控件标识、类型和时间内容识别，支持原生时钟子窗口回退；不按 Windows 版本号分支。Windows 更新仍可能改变控件结构。
- 原生接管必须实测：直接打开、无明显原生面板闪现、重复点击和外部点击关闭、Esc、通知铃铛、Win+N、Explorer 重启、多屏及不同 DPI。未测项目不能视为通过。
- ICS 请求限制为 5 MiB、25 秒、最多 5 次 HTTPS 重定向；可视六周之外不展开日程。
- 解析独立进程限制为 10 秒、256 MiB 和 10,000 条展开事件。超限视为刷新失败，保留上次缓存。
- 日历浏览范围为 1901—2100。
- 本项目未对可执行文件进行商业代码签名。

第三方许可见 `THIRD-PARTY-NOTICES.md` 和 `Licenses`。

兼容目标为 Windows 11 各版本 x64（安装最低构建 22000）。此前 25H2 版本已由用户实测；1.0.1 的任务栏改动需重新实机验收，23H2 及其他版本不能仅凭构建通过视为已验证。遇到入口未连接，请运行 `WinCalendar.exe --probe-clock clock-probe.txt`，提供结构诊断结果；诊断不输出控件名称或订阅链接。
