# WinCalendar 安装包

在 PowerShell 7 中运行：

```powershell
./Installer/build-installer.ps1 -IsccPath 'C:\路径\ISCC.exe'
```

需要 .NET 8 SDK 和已安装的 Inno Setup，可通过 `-NuGetSource` 指定本地 NuGet 源。脚本先运行现有检查并从干净目录生成独立运行包，然后生成 `publish/installer/WinCalendar-Setup-{版本}-x64.exe` 及 `SHA256SUMS.txt`。版本号取自工程配置。

安装包仅安装到当前用户，默认目录为 `%LOCALAPPDATA%\Programs\WinCalendar`，包含运行时及 `release-files.json`。支持 Windows 11 x64，提供简中、繁中、英文、日文；开始菜单快捷方式默认创建，桌面快捷方式可选。安装完成可启动程序，自启动由应用设置控制。

首次安装和覆盖安装均显示安装目录选择页，覆盖安装默认填入上次目录，允许修改。任务列表按 DPI 设置内部缩进和最小行高。升级沿用固定安装标识。安装、卸载时要求先从应用设置退出，不强制终止程序。交互卸载提供“保留订阅和设置”复选框，默认不勾选；继续卸载会删除 `%LOCALAPPDATA%\WinCalendar` 下的设置、订阅、缓存和更新备份，勾选后保留。取消卸载不删除数据，静默卸载默认保留。目录链接及无法删除的文件会保留并提示。仅清除指向安装目录的自启动记录。

安装包未签名，Windows 可能显示未知发布者或信誉提示。脚本不上传 Release，也不生成安装包的在线更新资产；在线更新使用发行脚本同时生成的 ZIP 和校验文件。

兼容目标为 Windows 11 各版本 x64（安装最低构建 22000）。此前 25H2 版本已由用户实测；1.0.1 的任务栏改动需重新实机验收，23H2 及其他版本不能仅凭构建通过视为已验证。遇到入口未连接，请运行 `WinCalendar.exe --probe-clock clock-probe.txt`，提供结构诊断结果；诊断不输出控件名称或订阅链接。

更新安全说明：1.0.1 更新与恢复只允许普通权限运行。恢复记录使用版本化格式，绑定发起程序目录并校验文件清单、大小、SHA-256 与进程路径。旧格式或校验失败时保留记录和备份，不自动执行旧工作程序，请使用新版安装包覆盖修复。已安装早期构建 1.0.1 的用户须手动覆盖安装，同版本不会触发在线更新。摘要用于发现损坏及不一致，不能防御已完全控制当前账户的程序。

订阅网络安全：仅支持公网 HTTPS 直连，不使用系统代理或自动 Cookie；本机、私网和特殊用途地址（含重定向、混合 DNS 结果）会被拦截。依赖代理或内网的旧订阅仍保留配置和有效缓存，但可能无法刷新。GitHub 更新下载策略不变。

订阅地址存储：所有地址使用 Windows DPAPI CurrentUser 加密，旧明文配置首次加载时自动迁移，不另存明文备份。跨电脑或用户复制配置后可能需要重新填写地址；无法解密的订阅保留密文及缓存并暂停网络刷新，不影响其他订阅。日程缓存仍是明文，外部历史明文备份不会自动清理。此保护不能防御已控制同一 Windows 账户的程序，也不等于可安全分享全部配置或缓存。早期构建 1.0.1 用户请使用新安装包覆盖安装。

1.0.2 跨版本更新：兼容 1.0.0 旧记录的启动确认，仅向经过目标目录、工作进程和当前子进程核验的事务发送确认，不执行旧记录的文件或恢复操作。更新启动时暂缓订阅刷新、设置保存及 DPAPI 迁移，等待工作进程提交完成后再开放。旧版已完成或已回滚的合法记录不会反复提示，旧版未完成记录仍需安装包修复。不会替换线上 1.0.1 资产；真实线上升级需发布 1.0.2 后验收。
